# Source intake / provenance

- Bibliography is a **curated metadata registry**; no downloaded copyrighted texts.
- `evidence_level` tells what has been inspected, NOT whether its claims are true.
- `rule_authority: none` means NO executable rule was approved from that source.
- `selection` is prioritization for future reading and review, not scientific endorsement.
- Source URL links identify the record; an `official_scope_checked` TCVN entry needs revisiting for legal amendments and local applicability at time of design.
- `watchlist.yaml` lists review locations; the watcher checks access only. It does not detect or certify new content automatically yet.
